# ScienceComputer Product Universe

ScienceComputer is organized around technical capability rather than a small retail assortment.

The product universe covers:

- Computing
- Processors
- Computer components
- Electronics
- Embedded development
- Sensors
- Robotics
- Mechanical systems
- Engineering
- Instrumentation
- Laboratory equipment
- Physics
- Chemistry
- Materials
- Fabrication
- 3D printing
- Power
- Networking
- Communications
- Aerospace
- Automotive
- Energy
- Medical technology
- Consumer electronics
- Displays
- Audio
- Security
- Tools
- Connectors and cables
- Software
- Replacement parts
- Project kits

This file defines PRODUCT CLASSES.

A product class is not automatically a real purchasable product.

Real products are represented separately by:

- manufacturer
- manufacturer part number
- technical specifications
- supplier
- price
- inventory
- documentation
- verification
- compatibility
