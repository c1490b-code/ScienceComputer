# ScienceComputer

A new technical/scientific computer environment built directly on Termux
and displayed through Termux:X11.

## Foundation

- Termux runtime
- Termux:X11 graphics
- Native development tools
- Git/GitHub
- C/C++
- Python
- Rust
- Scientific computing
- Engineering
- Design
- Simulation
- Visualization
- AI

This project does not require Debian, Ubuntu, XFCE, or another Linux
distribution as its foundation.

## Architecture

Android
└── Termux
    └── ScienceComputer
        └── Termux:X11
            └── ScienceComputer Desktop
